# BJTU汇编研究型实验

## 简介
本仓库为汇编与接口技术课程研究型作业，方向是二者之中的汇编方向。

题目为 “基于 ARM 汇编的 Matmul 矩阵乘法算子的实现以及优化”，基于 C++ 实现了纯高级语言版本的朴素矩阵乘法算子，并分别编写了普通矩阵乘法、基于鲲鹏平台的循环展开、地址计算优化、NeonSIMD优化的四种 arm 汇编作为 benchmark 进行测试。

## 运行方法

在 aarch64 平台的 bash 中运行 'make' 命令（确保有 make 工具），并 './matmul_test' 即可。程序会随机生成两个指定长宽的二维矩阵、以及其正确的乘法所得结果到 pwd 下，然后运行四种基于 ARM 汇编的矩阵乘法算子，并对比性能，然后输出到终端。
