# BJTU汇编研究型实验

## 简介
本仓库为汇编与接口技术课程研究型作业，方向是二者之中的汇编方向。

题目为 “基于 ARM 汇编的 Matmul 矩阵乘法算子的实现以及优化”，基于 C++ 实现了纯高级语言版本的朴素矩阵乘法算子，并分别编写了普通矩阵乘法、基于鲲鹏平台的循环展开、地址计算优化、NeonSIMD优化的四种 arm 汇编作为 benchmark 进行测试。

## 环境依赖
1. 操作系统: Linux
2. 运行平台: AArch64 / ARM64
3. 编译器: g++
4. 构建工具: Makefile

## 运行方法

在 bash 中运行 'make' 命令即可编译并链接该项目中的 cpp 代码和汇编代码，并生成可执行文件 matmul_test，接着运行该文件即可。程序会不断从 stdin 读取指定的两个矩阵的行、列、以及随机生成数字的范围，并据此随机生成两个指定长宽的二维矩阵，读入 -1 表示终止测试程序。在运行运行四种基于 ARM 汇编的矩阵乘法算子之后，程序会对比其和 cpp 朴素实现的性能差异，并将结果输出到终端，同时将被测试的矩阵和正确结果以 txt 的形式保存到同路径下。
